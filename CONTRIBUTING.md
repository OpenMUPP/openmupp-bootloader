# Contributing to openmupp-bootloader

## Branches

All changes go to `master`.
Open a pull request for each change.

## Developer Certificate of Origin

Each commit must have a `Signed-off-by` line with your name and e-mail address:

```sh
git commit -s
```

The line tells that you agree to the [Developer Certificate of Origin 1.1](https://developercertificate.org/).
You keep the copyright of your contribution.
You give the contribution under the license of this project: GPL-3.0-or-later.

Do not submit code that you do not have the right to submit, for example code from a vendor tool or from a project with a license that is not compatible.
Tell us the source and the license of each third-party file.
